UNIT 1: INTRODUCTION TO PROGRAMMING

📚 Short Questions

1. What is a program?

A program is a set of instructions written to perform a specific task on a computer.

2. What is programming?

Programming is the process of writing instructions for a computer to solve a problem.

3. What is a programming language?

A programming language is a language used to write instructions that a computer can understand and execute.

4. What is a high-level language?

A high-level language is a programming language that is easy for humans to read and understand.

5. What is a low-level language?

A low-level language is a programming language that is close to the machine language of a computer.

6. What is machine language?

Machine language consists of instructions written in binary digits, 0 and 1.

7. What is an algorithm?

An algorithm is a step-by-step procedure used to solve a problem.

🔄 Difference Between High-Level and Low-Level Languages

High-Level Language Low-Level Language
Easy for humans to understand. Closer to machine language.
Uses simple English-like instructions. Uses machine-oriented instructions.
Easy to write and debug. More difficult to write and debug.
Examples: Python, Java, C++ Examples: Assembly Language, Machine Language
